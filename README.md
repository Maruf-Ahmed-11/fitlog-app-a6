# FitLog

## Short Description
FitLog is a modern gym and workout companion web application designed for focused fitness training. It enables users to browse a library of exercises, view technical movement specifications, customize daily routines, and track their workout plans in real time.

## Live URI
https://fitlog-app-a6-bice.vercel.app

## Used Tech Stack
- **Framework:** Next.js (App Router)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS & daisyUI
- **Notifications:** React Toastify
- **State Management:** React Context API

## Key Features
- **Responsive Workout Library:** Dynamic grid showcasing workout routines fetched from a live API with category badges, duration, calories, and difficulty levels.
- **Interactive Routine Planner:** Easily add exercises to "Today's Plan" or "Save for Later" with real-time counter updates across the app navigation.
- **Dynamic Workout Detail Pages:** Dedicated routes (`/workout/[id]`) showing exercise imagery, targeted muscle groups, and step-by-step execution instructions.
- **Live Metrics Dashboard:** The "My Plan" page calculates and updates total workout duration, cumulative calories burned, and total exercises planned.
- **Plan Management & Sorting:** Filter and sort planned routines by Duration, Calories, or Rating, with quick actions to complete or remove exercises.
